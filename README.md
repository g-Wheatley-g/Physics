# Physics. Test

Справочник по физике с тремя вкладками. Поиск сужает список по мере ввода, алфавитный каталог показывает все вопросы с ответами, а тест позволяет выбрать 30 вопросов вручную или получить случайную подборку. После прохождения можно увидеть результат и правильные ответы.

Для локального просмотра откройте **dist/index.html** в браузере. Достаточно скачать папку **dist** целиком.

Вопросы и ответы из документа **ФИЗИКА_ВОПРОСЫ.docx** находятся в **dist/questions.js**. Совпадающие пары вопроса и ответа объединены. Различающиеся ответы на один и тот же вопрос показаны вместе. У обнаруженных неполных условий есть отметка.

Файл **dist/quiz-bank.js** содержит по три неверных варианта для каждого задания теста. Верный ответ берётся из **dist/questions.js**. Если формулировка вопроса изменилась при повторном импорте, обновите её и в банке теста.

Чтобы обновить вопросы, выполните команду из корня репозитория с помощью Python 3.

    python3 scripts/import_questions.py "ФИЗИКА_ВОПРОСЫ.docx"
