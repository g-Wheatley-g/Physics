# Архив версий Physics. Test

Каждая версия хранится в отдельной папке. Нумерация архива начинается с **2.0**. Для каждой следующей версии добавляется новая папка.

В [2.0](2.0/) находится сборка с вопросами из ЛМС и оригинальными изображениями. Для локальной проверки скачайте ZIP, распакуйте его целиком и откройте **Physics-Test-LMS/index.html**.

В [3.0](3.0/) находятся текстовые вопросы из ЛМС, расширенный тест и три цветовые темы. Для локальной проверки распакуйте ZIP и откройте **Physics-Test-3.0/index.html**.
